# University Course Registration System

## Project Overview
This project is a web-based University Course Registration System developed to simplify the process of course registration for students and administrators. It allows students to view available courses, register for them, and manage their course schedules. Administrators can add, update, and delete courses as well as view student registrations.

## Features
- Student Registration and Authentication
- Course Enrollment and Management
- View and Manage Course Schedules
- Admin Dashboard for Course Management

## Technologies Used
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MongoDB

## Installation and Setup
1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/university-course-registration-system.git
   ```
2. Navigate to the project directory:
   ```bash
   cd University-Course-Registration-System-Web-Engineering
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Configure the database and server URL in the configuration file.
5. Start the server:
   ```bash
   node server.js
   ```
6. Access the application at `http://localhost:3000`.

## Usage
- **Students:** Sign up or log in to register for courses.
- **Administrators:** Log in to manage courses and view student enrollments.

## Folder Structure
- `public/`: Contains frontend assets.
- `routes/`: Defines API endpoints.
- `models/`: MongoDB schemas.
- `views/`: EJS templates for dynamic rendering.
